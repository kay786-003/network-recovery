# 待修復問題清單

## 使用方式

本文件追蹤尚未解決的跨電腦部署風險及正式實機驗收。優先級表示使用影響，不代表已授權發行。完成項目應更新狀態並記錄驗證證據；不要把私人網路診斷、SSID、網卡 GUID 或密碼寫入此文件。

## 開放項目

### ISSUE-001 — 外網探測服務受限時可能誤判斷線

- 狀態：不處理（2026-10-28 決定，依 D0009；保留記錄）
- 優先級：低
- 影響：公司代理、防火牆或僅允許內網的環境若封鎖所有探測服務，監控可能把可用的內網連線判定為離線，之後重啟網卡或電腦。首次設定預檢只能提前發現當下的問題，不能保證日後網路政策不變。
- 建議處理：不實作多端點或分層探測。使用者以遠端連回公司電腦為主要用途，寧可錯判後重新啟動，也不要因判定過於保守而長時間無法連線。若日後要改，須先取代 D0009。

### ISSUE-002 — 發行 EXE 尚未簽署

- 狀態：待處理
- 優先級：中
- 影響：Windows 可能顯示未辨識的發行者或下載警告，降低一般使用者對附件的信任。
- 建議處理：取得適用的程式碼簽署憑證，簽署正式 EXE 並在發行流程驗證簽章；未具備憑證前維持明確的未簽署說明。

### ISSUE-003 — 新版 EXE 的端到端實機驗收未完成

- 狀態：部分驗收
- 優先級：高
- 影響：純資料測試與建置無法證明實際 Wi-Fi 設定、網卡修復、開機監控及重新啟動在不同 Windows 10/11 電腦和網卡驅動上都正常。
- 已驗證：使用者 2026-10-28 回報斷網修復與重新啟動電腦兩條主要路徑成功（見 `docs/VERIFICATION.md`）。
- 建議處理：續驗真實密碼寫入與錯誤密碼、開機後 300 秒觸發路徑、安裝失敗還原、舊版覆蓋升級及目標 SSID 不在範圍時的行為；每次實機操作須取得當次授權並記錄去識別結果。

### ISSUE-004 — Windows 10 最低版本尚未明確登記

- 狀態：待處理
- 優先級：中
- 影響：README 目前以 Windows 10/11 概括支援範圍，但不同 Windows 10 版本內建或可安裝的 .NET Framework 版本不同。
- 建議處理：確認最低 Windows 10 版本及受支援更新狀態，並同步更新 README、驗收矩陣與 CI／實機驗證記錄。
