# 開發路線圖

## 目前狀態

目前為第一階段，GitHub 預發行版本 `v0.1.0`、EXE 產品版本 `0.1.0`／檔案版本 `0.1.0.0`。已具備設定介面、單網卡／單 Wi-Fi、自動連線及背景監控；新版 EXE 的完整實機斷網與重啟驗收尚未完成，因此不標示為穩定版本。路線圖只描述方向，不授權 Agent 自動開工。

## 第一階段

- [x] 管理員權限的單一 Windows EXE。
- [x] 列出網卡並選擇一張要修復的網卡。
- [x] 選擇一個 Wi-Fi，缺少已存設定時要求密碼並設定自動連線。
- [x] 儲存、啟用與停止背景監控。
- [x] 固定 180 秒／60 秒／300 秒的正式流程。
- [x] 建置、格式、密碼／XML 及只讀實機檢查。
- [ ] 新 EXE 的真實密碼寫入、斷網修復與開機後重啟驗收。

## 第二階段

- [ ] 多個 Wi-Fi 及明確的重連優先順序。
- [ ] 找不到第一個 SSID 時依序嘗試下一個。
- [ ] 介面可設定多久斷網後修復網卡。
- [ ] 介面可設定修復後多久仍未恢復才重啟。
- [ ] 介面可設定重開機後多久再次進入修復／重啟流程。
- [ ] 設定遷移與上述時間、順序的回歸測試。

## 開始下一項工作的條件

依使用者當次指示選擇範圍。實機測試先確認當次操作授權；第二階段實作前先釐清多 Wi-Fi 與時間設定的驗收條件，更新架構決策後再改程式。不要因為清單未勾選就自行新增功能、發行版本或部署。
